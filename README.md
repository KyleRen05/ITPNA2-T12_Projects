## ITPNA2-12_SummativeAssessment - Aircraft Telemetry API & Alert System
<p>Tech Stack: Python (HTTP Server), SQLite, JSON, SMTP<br/>
Overview: Engineered a custom Python HTTP server to ingest, evaluate, and store simulated real-time aircraft telemetry data via JSON.<br/>
Key Features: Built a REST-style API supporting POST requests for live data ingestion and GET requests for historical logs. Integrated an automated watchdog that evaluates live metrics against safety thresholds and instantly triggers local SMTP email alerts for critical system anomalies.
